Módulos de gestão e documentação
Memorial de Cálculo Automático — botão que agrega todos os dados do projeto (sondagens, cargas, capacidade, dimensionamento, quantitativos) e gera um PDF estruturado com capa, memórias de cálculo e tabela resumo, pronto para anexar ao projeto executivo.
Painel de Status da Obra (dashboard de acompanhamento) — visual tipo kanban/progresso que mostra, por bloco ou por pilar, o status de execução em campo (executada, a executar, com NC, aguardando ensaio), integrado com os dados do módulo de Execução (CheckFund) já existente.
Histórico de Revisões — versionamento simples do projeto, permitindo ao engenheiro registrar cada revisão com data, autor e descrição das alterações. Útil para o RRT/ART e para auditorias de qualidade.
Verificação de Recalques
Estimativa de Custos (Módulo 12) — a partir dos quantitativos, o usuário informa preços unitários (concreto/m³, aço/kg, execução/m, mobilização) e o sistema gera o orçamento com BDI configurável e resumo por tipo de serviço.
